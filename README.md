### 🌱 Sustainable Token Analyzer
> Web app that analyzes AI prompts for token count, energy usage, API cost, and carbon footprint — then uses NVIDIA's Qwen 2.5 72B to rewrite them into leaner, more efficient versions. Tracks session history with live charts.

**What was built:**
- Full **React + TypeScript** frontend with 8 components, custom hooks, and typed interfaces
- **Netlify serverless function** as the API backend — real production architecture
- **NVIDIA API integration** (Qwen 2.5 72B) for AI-powered prompt optimization
- Client-side fallback optimizer using regex-based filler removal — works offline too
- Carbon calculations based on real grid data: `0.386 kg CO₂/kWh` global average
- **Recharts dashboard** tracking tokens analyzed, energy saved, cost saved, and CO₂ reduced across sessions
- 4-tab layout: Dashboard · Analyzer · Comparison · Suggestions
- Session history persisted in browser — cumulative stats update in real time

**Why it exists:** Longer prompts cost more, use more energy, and produce more CO₂. This tool quantifies that and helps fix it.

**Stack:** `React` · `TypeScript` · `Tailwind CSS` · `Netlify Functions` · `NVIDIA API` · `Recharts` · `Vite`
